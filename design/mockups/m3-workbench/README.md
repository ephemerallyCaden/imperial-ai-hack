# M3 Workbench (primary tone: deep)
Concept: an analysis-workbench layout with a cooler #F6F7F8 inspector and dock, a hairline floating tool strip on the canvas, and mono tabular readouts, still flat and journal-honest.
Differs from the others: sans-dominant (serif only on the "Stitch" title), tools and preset live in one top strip over the canvas, dense booktabs table, scrubber shares one time axis with the ribbon chart, a tone switcher (mockup only) in the header.
Tones are muted derivations loosely anchored on Monk tones; illustrative, not clinical. Open `index.html?tone=light|medium|deep`.
Type: system serif (title), SF/Helvetica sans (UI), ui-monospace (readouts); no web fonts.
Strengths: all controls reachable without leaving the canvas; chart, scrubber and t0 read as one object; legend swatches carry non-colour cues.
Strengths: the honesty chip and source line sit on the canvas itself and never collapse with the panel.
Risks: dock is 124 px, so the ribbon plot is only 64 px tall and the ensemble members are hard to read.
Risks: dense chrome edges toward "dashboard"; the 5-row legend plus table fills the panel with no room to grow.
Risks: the Draw (pressed) and Heal (blue) states compete; the minimap viewport box is small on the deep tone.

# M4 Minimal
Concept: the canvas is the screen; chrome is hairlines, a 48 px rail, one overlay key and a single data graphic (the forecast ribbon).
Differs: panel collapsed to a rail with a scorecard flyout; forecast summary is a one-line strip; state key is a corner overlay; ladder on the left edge.
Primary tone: medium (light and deep also render; `?tone=light|medium|deep`). Tones are illustrative muted derivations, not clinical skin-tone data.
Type: Charter serif (wordmark, captions), -apple-system sans (UI), ui-monospace (readouts); tabular numerals; system fonts only.
Strengths: 1) canvas takes ~75% of the screen; 2) all five rules and cues stay visible; 3) every brief item present with no cards or shadows.
Strengths (cont.): the scrubber shares the ribbon's time axis, so t0 and the playhead read once.
Risks: 1) the overlay key and flyout cover canvas edges; 2) the ribbon is only ~74 px tall, so the 50%/90% bands look thin late in the run.
Risks (cont.): 3) icon-only rail needs tooltips and discovery; the 11 px axis and key text is small.
Preset segmented control and Draw/Heal/Clear sit in a top-left strip; no sliders. Playback honours prefers-reduced-motion (nothing animates).
All cells, curves and scores are simulated or illustrative.

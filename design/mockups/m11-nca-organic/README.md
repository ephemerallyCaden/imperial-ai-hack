# M11 NCA organic

Same engine and numbers as M10, drawn as soft blobs with no grid or outlines. Moves and divisions are interpolated between steps; a dividing cell is pale with two nuclei and the daughter eases out. Open `index.html` (`?tone=...&member=...&p=<step>&play=0`).

Toggle **Division on/off** (`?div=0`): off = movement only (the WHAD mitomycin case); the ensemble ribbon is recomputed for the chosen setting.

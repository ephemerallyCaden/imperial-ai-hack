# M10 NCA discrete grid

One lattice site = one cell, stepped. Visible square sites, state colours, a dot on cells that moved, a split mark on dividing cells. Shared engine: `design/shared/ncamock.js` (stochastic lattice rules standing in for the trained NCA ensemble; 12 members; ribbon with t0). Open `index.html` (`?tone=light|medium|deep&member=1-12&p=<step>&play=0`).

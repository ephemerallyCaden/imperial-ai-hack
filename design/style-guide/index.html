2 · Cell states (3D columns + legend)

Skin look. Checked under protan / deutan / tritan simulation (closest pair ΔE ≥ 17) and in greyscale (wound 8 · edge 38 · intact 63 · new 88 · dividing 100). Rendered with toon shading, age colouring and an 8° cool hue shift. Height = local density; colour = state; dividing = dark centre dot.

Outside a box selection: matte greyscale, one step per state so the rest of the wound still reads.

7 · Honesty labels (required)
  • Simulated cells, not tracked cells · always visible on the dish
  • Recorded run · on Assay playback; Sped up · whenever speed > 1×
  • Simulation on recorded data · Ops scoreboard and scheduler
  • Simulation, preset parameters (WHAD part II fits, follow rule) · Draw
  • Uncalibrated · simulator / NCA spread and outlines
  • Untested · “stop, likely to close”
  • Research use only, not for diagnosis or treatment · footer + Help
  • Colours illustrative, not clinically calibrated · tissue tone help
Do: state the decision first, then the number that drove it.
Do: pair every colour with a word, icon, hatch or dot.
Don't: call any simulator or NCA spread a “90% interval”.
Don't: use the leading-edge red for text (it's a cell state, not a status colour).
Don't: add a second accent colour; status uses amber + words.
8 · Accessibility + motion
  • Contrast on --bg: ink 17:1 · dim 6.6:1 · amber 9.3:1 · faint 3.4:1 (decoration only)
  • Focus ring: 2 px amber with a 2 px background gap (--focus); every control reachable by keyboard
  • Shortcuts: Space play · ←/→ step · +/− zoom · S select · Esc clear · R reset camera · ? shortcuts
  • Camera fly 1.4 s (--ease); panels 240 ms; all motion off under prefers-reduced-motion
  • Charts get role="img" + an aria-label that states the key number

# Docs

Shared brainstorming space. Everything here is committed and pushed so all three of us (and Claude) see the same thinking.

- `brainstorm.md`: running idea log. Append, don't rewrite others' entries.
- `decisions.md`: short record of choices made (what, why, who).
- Add one file per bigger topic, e.g. `docs/demo-flow.md`, `docs/api-notes.md`.

Rules:
- Pull before editing, commit small, push often. Prefix your entries with your name.
- Claude: read `docs/` before proposing features or architecture, and record decisions in `decisions.md`.
